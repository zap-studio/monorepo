# Sync docs

Ship docs together with any user-facing API or behavior change:

- Page content lives in `apps/docs/src/pages/<package>/*.mdx`.
- Add new pages to the sidebar/topNav in `apps/docs/vocs.config.ts`.
- Update the package `README.md`, and the root `README.md` when a package is added or removed.
