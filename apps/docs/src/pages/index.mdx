# Zap Studio

Zap Studio is a collection of TypeScript packages for core app capabilities: typed HTTP calls, authorization policy checks, retry policies, schema validation, and webhook processing. Each package works on its own, so you adopt only what you need.

## Design Principles

Every package follows the same rules:

- **Type safety.** APIs are fully typed, and runtime validation backs the types where data crosses a boundary, such as HTTP responses and webhook payloads.
- **Framework-agnostic.** Packages depend on standard runtime APIs, not on a specific framework, so they stay portable across stacks.
- **Composable.** Packages are small building blocks you combine as needed — for example, retry policies around fetch calls, or Standard Schema validators inside webhook handlers.

## Packages

| Package | What it covers |
| --- | --- |
| [`@zap-studio/fetch`](/fetch) | Type-safe HTTP requests with schema-validated responses |
| [`@zap-studio/permit`](/permit) | Declarative authorization policies and permission checks |
| [`@zap-studio/retry`](/retry) | Composable retry policies with fixed and exponential backoff |
| [`@zap-studio/validation`](/validation) | Standard Schema utilities and consistent validation errors |
| [`@zap-studio/webhooks`](/webhooks) | Webhook routing, signature verification, and payload validation |
